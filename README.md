# apps 4 HA
Apps (formerly addons) for home-assistant

<img src="./miniDLNA/icon.png" width="10"> [miniDLNA](https://github.com/Moozzuzz/HA-addons/tree/main/miniDLNA) miniDLNA is a lightweight media (audio, pictures & video) server, which aims to be fully compliant with DLNA/UPnP-AV clients. This app (~addon) provides you with the latest miniDLNA on Alpine, ready to go.
